# Media strategy I'd actually use

Don't overload the page with images.

| Section         | Media                             |
| --------------- | --------------------------------- |
| Hero            | **Custom business-launch visual** |
| Problem         | Before/After UI                   |
| Transformation  | Process diagram                   |
| What's included | Icons + document/UI previews      |
| Website         | **Real website screenshots**      |
| Who it's for    | Simple illustrations              |
| How it works    | Timeline                          |
| Why JurisTech   | Law + technology visual           |
| Pricing         | No image                          |
| FAQ             | No image                          |
| Final CTA       | Abstract branded background       |

### The most important media asset

**Your actual website work.**

I'd create 3–5 polished mockups from the website system you've built:

1. Desktop homepage
2. Mobile homepage
3. Services section
4. Contact/WhatsApp section
5. One alternate industry template

Then reuse these across the page.

That turns the statement **"we build professional websites"** into visible proof.

And because the whole Business Launch strategy is based on selling a transformation rather than a list of services, the page should visually tell this story:

**Unstructured business → Registered company → Legal structure → Professional website → Ready to operate.**

That's the core design narrative.
